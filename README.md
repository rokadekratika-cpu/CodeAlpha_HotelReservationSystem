# Hotel Reservation System

## About the Project
The Hotel Reservation System is a web-based application developed using Java Servlets, HTML, CSS, and MySQL.

It allows users to view rooms, make reservations, cancel bookings, and complete a simulated payment process.

## Technologies Used
- Java
- Java Servlets
- HTML
- CSS
- MySQL
- Apache Tomcat
- NetBeans IDE

## Features
- Home page
- View hotel rooms
- Room search
- Room booking
- Booking cancellation
- Simulated payment
- MySQL database integration

## Database Setup
1. Install MySQL Server.
2. Open MySQL Command Line Client.
3. Execute the SQL commands from `hotelreservation.sql`.
4. Ensure the database and tables are created successfully.

## How to Run
1. Open the project in NetBeans.
2. Configure the Apache Tomcat server.
3. Configure the MySQL database connection.
4. Deploy and run the project.
5. Open the application in your browser.
